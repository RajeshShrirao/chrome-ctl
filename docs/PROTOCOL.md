# Wire Protocol Specification: `chrome-ctl`

**Document Version:** 1.0  
**Transport:** WebSocket (`ws://127.0.0.1:9229/ws`)  
**Encoding:** UTF-8 JSON  
**Framing Model:** JSON-RPC 2.0 Bi-directional Envelopes  

---

## 1. Connection Handshake & Authentication

### 1.1 Handshake Flow
1. Extension connects to `ws://127.0.0.1:9229/ws?token=<64_CHAR_HEX_TOKEN>`.
2. Daemon verifies the token against `~/.chrome-ctl/auth_token`.
3. If token matches, connection is accepted, and daemon broadcasts:
   ```json
   {
     "jsonrpc": "2.0",
     "method": "system.ready",
     "params": {
       "version": "1.0.0",
       "daemonUptimeSec": 42,
       "attachedTabs": []
     }
   }
   ```
4. If token is invalid or missing, daemon responds with HTTP `401 Unauthorized` and terminates the TCP socket immediately.

### 1.2 Heartbeat (Liveness Keep-Alive)
* The Extension's Offscreen Document sends a ping every **15 seconds**:
  ```json
  { "jsonrpc": "2.0", "method": "system.ping", "params": { "timestamp": 1729725600 } }
  ```
* Daemon replies immediately with:
  ```json
  { "jsonrpc": "2.0", "result": { "status": "pong", "timestamp": 1729725600 }, "id": null }
  ```

### 1.3 Automatic Pairing
The extension obtains the token without manual copy/paste.

**Request** — `POST http://127.0.0.1:9229/pair` with:
```http
X-Chrome-Ctl-Pair: 1
Origin: chrome-extension://<extension-id>
```
An empty `Origin` (non-browser local client) is also accepted.

**Success** — `200 OK`, `Cache-Control: no-store`:
```json
{ "token": "<64_CHAR_HEX_TOKEN>" }
```

**Rejection** — `403 Forbidden` when any of these fail:
* `Host` is not a loopback name (`127.0.0.1`, `localhost`, `::1`).
* The TCP peer address is not loopback.
* `X-Chrome-Ctl-Pair` is not exactly `1`.
* `Origin` is present and is not `chrome-extension://…`.

A web page cannot send the custom header cross-origin without a CORS preflight, which the daemon does not answer, so page scripts cannot read the token. `GET /pair` returns `405`.

**Client behavior.**
* Offscreen document polls `/pair` every 5 seconds while no token is stored, and retries before reconnecting after a failed WebSocket.
* On success it asks the service worker to persist the token under `chrome.storage.local` key `chromeCtlToken`.
* `401`/failed WebSocket with a stored token triggers one pairing refresh before the exponential backoff resumes.
* Manual entry remains available in the popup and via `chrome-ctl token`.

**Rotation.** Delete `~/.chrome-ctl/auth_token` and restart the daemon. The extension detects the rejected socket, re-pairs, and reconnects automatically.

## 2. Standard Message Framing

### 2.1 Request Envelope (CLI $\rightarrow$ Daemon $\rightarrow$ Extension)
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "method": "<domain>.<action>",
  "params": {
    "tabId": 142058291,
    "..." : "..."
  }
}
```

* `id` *(string, required)*: Monotonically increasing or UUID string generated by the caller.
* `method` *(string, required)*: Method in `<domain>.<action>` syntax.
* `params` *(object, optional)*: Command-specific arguments. If `tabId` is omitted, the Extension defaults to the currently active tab.

### 2.2 Success Response Envelope (Extension $\rightarrow$ Daemon $\rightarrow$ CLI)
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "result": {
    "status": "ok",
    "data": {}
  }
}
```

### 2.3 Error Response Envelope
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "error": {
    "code": -32001,
    "message": "Element not found or not interactable",
    "data": {
      "elementId": 5,
      "details": "Element [5] was scrolled out of viewport or mutated before click."
    }
  }
}
```

### 2.4 Event Envelope (Unsolicited Extension $\rightarrow$ Daemon)
```json
{
  "jsonrpc": "2.0",
  "method": "event.<eventName>",
  "params": {
    "tabId": 142058291,
    "data": {}
  }
}
```

## 3. Core RPC Methods

### 3.1 Session & Tab Management

#### `session.status`
Checks connection health, active Chrome tabs, and debugger attachment status.
* **Params:** `{}`
* **Result:**
  ```json
  {
    "status": "ok",
    "extensionConnected": true,
    "activeTab": {
      "tabId": 142058291,
      "title": "LinkedIn - Feed",
      "url": "https://www.linkedin.com/feed/"
    },
    "debuggerAttached": true
  }
  ```

#### `tab.list`
Returns the open tabs of one window: `windowId` when given, otherwise the tracked automation window, otherwise the last focused window.
* **Params:** `{ "windowId"?: number }`
* **Result:**
  ```json
  {
    "tabs": [
      { "tabId": 101, "title": "Google", "url": "https://www.google.com", "active": false },
      { "tabId": 102, "title": "LinkedIn", "url": "https://www.linkedin.com/feed/", "active": true }
    ]
  }
  ```

#### `tab.open`
Navigates the active tab or opens a new tab.
* **Params:**
  ```json
  {
    "url": "https://clutch.co/directory",
    "newTab": false,
    "windowId": 12
  }
  ```
  `windowId` is optional and only consulted with `newTab`; when it is omitted the extension uses the tracked automation window.
* **Result:**
  ```json
  {
    "tabId": 102,
    "url": "https://clutch.co/directory",
    "title": "Top Web Developers - Clutch",
    "loaded": true
  }
  ```

#### `tab.switch`
Makes `tabId` active inside its own window and moves the automation workspace to that window.
* **Params:** `{ "tabId": 101 }`
* **Result:** `{ "success": true, "activeTabId": 101 }`
  Activating a tab never raises its window, so the user keeps focus.

#### Window management
The extension stores the automation window id under `chrome.storage.local` (`chromeCtlAutomationWindow`) and validates it with `chrome.windows.get` on every read, so a window the user closed is dropped instead of targeted.

#### `window.list`
* **Params:** `{}`
* **Result:**
  ```json
  {
    "windows": [
      { "windowId": 10, "focused": true, "state": "normal", "tabCount": 3, "automation": false },
      { "windowId": 12, "focused": false, "state": "normal", "tabCount": 1, "automation": true }
    ]
  }
  ```
  `state` is Chrome's window state (`normal`, `minimized`, `maximized`, `fullscreen`).

#### `window.create`
Creates a window and makes it the automation window. Default `focused: false`, so the user's window keeps focus.
* **Params:** `{ "url"?: "https://example.com", "focused"?: false }`
* **Result:** `{ "windowId": 12, "activeTabId": 104, "tabCount": 1, "focused": false, "created": true }`
  With a `url` the call waits for the tab to finish loading before returning (30s budget).

#### `window.ensure`
Returns the live automation window, or creates one when none is tracked. Same result shape as `window.create`, with `created: false` on reuse.
* **Params:** `{}`

#### `window.use`
Re-points automation at an existing window, or clears the tracked id.
* **Params:** `{ "windowId"?: number, "focused"?: true }` — neither key clears the tracking; `focused` targets the window Chrome reports as last focused; an unknown `windowId` is an error.
* **Result:** `{ "windowId": 10, "activeTabId": 101, "tabCount": 3, "focused": true, "cleared": false }`, or `{ "cleared": true }` when tracking was removed.

#### `window.close`
* **Params:** `{ "windowId": 12 }`
* **Result:** `{ "success": true, "windowId": 12 }`
  The CLI refuses a focused window unless `--force` is passed, and closing the automation window clears the tracked id.

#### Implicit tab resolution
Every method that accepts an optional `tabId` resolves it in this order: explicit `tabId`, the active tab of an explicit `windowId`, the active tab of the automation window, then the active tab of the last focused window.

### 3.2 Observation & DOM Distillation

#### `page.snap`
Scans visible DOM and extracts the ultra-compact indexed element map.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "all"?: false,
    "formsOnly"?: false,
    "deep"?: false,
    "maxElements"?: 400
  }
  ```
* **Result:**
  ```json
  {
    "tabId": 102,
    "title": "LinkedIn - Feed",
    "url": "https://www.linkedin.com/feed/",
    "docId": "0f1e2d3c-...",
    "snapshotId": 3,
    "omitted": 0,
    "viewport": {
      "scrollY": 0,
      "viewportHeight": 900,
      "totalHeight": 4200,
      "percent": 21
    },
    "elements": [
      {
        "id": 1,
        "tag": "input",
        "type": "text",
        "label": "Search",
        "value": "",
        "state": "",
        "x": 310,
        "y": 28,
        "w": 240,
        "h": 34
      },
      {
        "id": 2,
        "tag": "button",
        "type": "button",
        "label": "Start a post",
        "value": "",
        "state": "",
        "x": 540,
        "y": 135,
        "w": 450,
        "h": 48
      }
    ],
    "formattedText": "SNAP 3 | TAB [102] LinkedIn - Feed | https://www.linkedin.com/feed/\nVIEWPORT: 0-900px of 4200px (21%)\n[1] <input:text> \"Search\" () @310,28\n[2] <button> \"Start a post\" @540,135"
  }
  ```

IDs are unique for the life of a document (`docId`) and never reused. Each snapshot increments `snapshotId`; the tag also appears as the `SNAP <n> |` prefix. `deep` adds rows, grid cells, and cursor-only candidates; `maxElements` caps the map (default 400) and `omitted` reports how many candidates were skipped. A footer line `OMITTED: n candidates` is appended when the cap is hit.

#### `page.read`
Extracts readable markdown, tables, or links from the page or a specific container.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id"?: 3,
    "selector"?: "main",
    "mode"?: "markdown | tables | links",
    "maxTables"?: 10,
    "maxLinks"?: 200
  }
  ```
* **Result (markdown, default):**
  ```json
  {
    "markdown": "# Feed\n\n**Rahul Verma** posted: Just launched our new pipeline..."
  }
  ```
* **Result (tables):**
  ```json
  {
    "tables": [
      {
        "index": 1,
        "caption": "Revenue",
        "headers": ["Region", "Q1"],
        "rows": [["North", "10"], ["South", "20"]]
      }
    ],
    "truncated": false
  }
  ```
* **Result (links):** `{ "links": [{ "text": "Docs", "href": "https://example.com/docs" }], "truncated": false }`

Links are deduplicated by absolute URL; `javascript:` and fragment-only hrefs are skipped. Tables promote `thead th`, then the first row with `th`, then row 1 as headers; that header row is not repeated in `rows`.

#### `page.wait`
Waits for a selector, body text, DOM idle, or network quiet. Timeouts return `matched: false` rather than an error.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "selector"?: "#results",
    "text"?: "Panel ready",
    "ignoreCase"?: false,
    "idle"?: false,
    "network"?: false,
    "quietMs"?: 500,
    "timeoutMs"?: 15000
  }
  ```
* **Result:**
  ```json
  {
    "waitedMs": 8420,
    "matched": true,
    "requests": 23
  }
  ```
When `network` is true the daemon counts in-flight CDP requests and resolves when the count is zero and no request activity occurred for `quietMs`. If the debugger cannot enable the Network domain (for example, DevTools owns the tab) the call fails with `-32004` instead of returning an empty result. `text` waits on rendered body text; `selector`, `text`, and `network` may be combined, and all conditions must hold before the same deadline.

### 3.3 Humanized Actions (Dispatched via `chrome.debugger`)

#### `action.click`
Executes Bézier trajectory mouse movement and dispatches trusted mouse click events.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id"?: 2,
    "at"?: { "x": 542, "y": 138 },
    "doubleClick"?: false,
    "snap"?: true
  }
  ```
* Exactly one of `id` or `at` is required. `at` is an exact viewport point in CSS pixels, as printed by `page.snap`; it is not a screenshot pixel.
* **Result:**
  ```json
  {
    "success": true,
    "action": "click",
    "target": { "id": 2, "tag": "button", "label": "Start a post" },
    "coordinates": { "x": 542, "y": 138 },
    "landedOn": "<button> \"Start a post\"",
    "urlChanged": false,
    "durationMs": 340,
    "snapshot"?: { /* Included if snap == true */ }
  }
  ```
`target` is omitted for coordinate clicks. `landedOn` names the topmost element at the click point and `urlChanged` compares the tab URL ~150 ms after dispatch. Both describe what the input hit, not whether the application accepted it.

#### `action.type`
Focuses target element and dispatches cadence keystrokes with variable delays and optional typos.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id": 4,
    "text": "Hello world! We are launching today.",
    "enter"?: true,
    "typoRate"?: 0.02,
    "snap"?: false
  }
  ```
* **Result:**
  ```json
  {
    "success": true,
    "charsTyped": 36,
    "durationMs": 2450,
    "typosInjected": 1,
    "verified": true,
    "verification": "exact",
    "readBack": "Hello world! We are launching today.",
    "stateDelta": "[6] <button:submit> \"Send\" is now (enabled)"
  }
  ```
`verification` is `exact`, `normalized` (whitespace-only difference), `empty`, or `mismatch`. The value is read back before any `enter` keystroke, with retries over 0/120/300 ms to absorb framework commit latency. `verified: false` with `empty` usually means a readonly or fully controlled field rejected the input.

#### `action.press`
Dispatches a trusted individual key press (`Enter`, `Tab`, `Escape`, `ArrowDown`, etc.).
* **Params:**
  ```json
  {
    "key": "Enter",
    "modifiers"?: ["Control"]
  }
  ```
* **Result:** `{ "success": true, "key": "Enter" }`

#### `action.scroll`
Executes momentum wheel scrolling with micro-pauses.
* **Params:**
  ```json
  {
    "direction": "down",
    "amount": 0.8
  }
  ```
* **Result:**
  ```json
  {
    "scrolledPixels": 720,
    "newScrollY": 720,
    "viewportPercent": 38
  }
  ```

#### `action.upload`
Attaches a local file to a file input node (`<input type="file">`).
* **Params:**
  ```json
  {
    "id": 5,
    "filePath": "/Users/user/Desktop/logo.png"
  }
  ```
* **Result:**
  ```json
  {
    "success": true,
    "fileName": "logo.png",
    "fileSize": 45120
  }
  ```

* **Params:**

### 3.6 Resilient Targets & Macro Replay

`page.describe` and `page.resolve` expose the multi-tier selector engine used by macros.

#### `page.describe`
* **Params:** `{ "tabId"?: 4, "id": 12 }`
* **Result:** `{ "target": { "testId"?: "...", "ariaLabel"?: "...", "role"?: "button", "text"?: "...", "tag"?: "button", "type"?: "...", "xpath"?: "...", "cssSelector"?: "..." } }`
* Resolves `id` against the latest snapshot index; returns `-32001` when the element is gone.

#### `page.resolve`
* **Params:** `{ "tabId"?: 4, "target": { ... }, "timeoutMs"?: 3000 }`
* **Result:** `{ "id": 12, "tag": "button", "type": "", "label": "Continue", "x": 410, "y": 650, "w": 120, "h": 36, "matchedTier": "ariaLabel" }`
* Tiers are attempted in order: `testId`, `ariaLabel` (+`role`), `text`, `xpath`, `cssSelector`. Polls every 150 ms until `timeoutMs` (default 3000, max 15000). The returned `id` can be passed to `action.click`, `action.type`, or `action.upload`.

Macro methods are handled by the daemon itself and replayed locally.

| Method | Params | Result |
| :--- | :--- | :--- |
| `macro.start` | `{ "name": "lead_search" }` | `{ "name", "started": true, "steps": 0 }` |
| `macro.save` | `{ "params"?: ["search_term"], "description"?: "..." }` | `{ "path", "name", "steps", "parameters" }` |
| `macro.list` | `{}` | `{ "macros": [{ "name", "description", "parameters", "steps", "modifiedAt" }] }` |
| `macro.run` | `{ "name": "lead_search", "vars": { "search_term": "Design Studios" } }` | `{ "macro", "stepsRun", "durationMs", "completed": true }` |

When replay cannot resolve or perform a step, `macro.run` fails with code `-32008` and data `{ "status": "macro_step_failed", "macro", "failed_step_id", "reason", "current_snapshot", "remaining_steps" }`.

### 3.7 Diagnostic & Escape-Hatch Methods

#### `page.attr`
Returns one element's identity, attributes, and geometry. Address it by snapshot `id` or by CSS `selector`.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id"?: 12,
    "selector"?: "div[role=combobox]"
  }
  ```
* **Result:**
  ```json
  {
    "docId": "0f1e2d3c-...",
    "snapshotId": 3,
    "tag": "a",
    "role": "link",
    "type": "",
    "label": "Documentation",
    "value": "",
    "state": "",
    "href": "https://example.com/docs",
    "src": "",
    "name": "",
    "elementId": "docs-link",
    "rect": { "x": 40, "y": 180, "w": 120, "h": 20 },
    "attributes": { "href": "/docs", "class": "nav-link" },
    "matches": 1
  }
  ```
`href` and `src` are resolved against `document.baseURI`. `matches` counts CSS matches and is `1` for snapshot IDs.

#### `page.eval`
Evaluates a JavaScript expression through CDP `Runtime.evaluate` on the attached tab. Page CSP does not apply because the script runs in the debugger's execution context.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "expression": "document.title",
    "awaitPromise"?: false,
    "timeoutMs"?: 5000
  }
  ```
* **Result:** `{ "json": "LinkedIn - Feed", "type": "string", "truncated": false }`
* `json` is the JSON-serialised value. Values that cannot be returned by value are retried through a `JSON.stringify(...)` wrapper. Output is capped at 100 000 characters; `truncated` flags a cut.
* A disabled daemon rejects this method with `-32011 FEATURE_DISABLED`. Every accepted call is audit-logged with the tab id, result type, and the expression truncated to 120 characters.

#### `page.net`
Returns requests observed while the debugger was attached.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "errorsOnly"?: false,
    "limit"?: 50,
    "sinceMs"?: 300000
  }
  ```
* **Result:**
  ```json
  {
    "entries": [
      {
        "requestId": "1042.7",
        "url": "https://example.com/api/items",
        "method": "GET",
        "type": "Fetch",
        "status": 200,
        "startedAt": 1729725600123,
        "durationMs": 182
      }
    ],
    "enabledAt": 1729725599000,
    "note": "collected only while the debugger is attached; enable via an action or wait --network"
  }
  ```
`errorsOnly` keeps entries with a network error or status ≥ 400. Entries are capped at 200 per tab, WebSocket/EventSource traffic is ignored, and `enabledAt` is `0`/absent until the Network domain has been enabled on the tab. `sinceMs` filters by request start time relative to now.

#### Snapshot identity on id-bearing requests

The service worker caches `{docId, snapshotId}` from the latest `page.snap` per tab and injects `expectedDocId` into content requests that address a snapshot id (`target`, `focus`, `describe`, id-scoped `read` and `attr`). If the page navigated in between, the content script rejects the request with `-32010 SNAPSHOT_STALE` before touching the DOM. The cache is cleared on `chrome.tabs.onUpdated` (`loading` or URL change) and `tabs.onRemoved`.

## 4. Error Code Reference

| Code | Name | Description |
| :--- | :--- | :--- |
| **`-32000`** | `CONNECTION_ERROR` | WebSocket or daemon bridge connection failed. |
| **`-32001`** | `ELEMENT_NOT_FOUND` | Specified element ID was not found in the current tab's active index map. |
| **`-32002`** | `ELEMENT_NOT_INTERACTABLE`| Target element is obscured, detached from DOM, or has `pointer-events: none`. |
| **`-32003`** | `TAB_NOT_FOUND` | The requested `tabId` does not exist or was closed. |
| **`-32004`** | `DEBUGGER_DETACHED` | `chrome.debugger` was forcibly detached or blocked. |
| **`-32005`** | `SSO_TIMEOUT` | No Google OAuth popup was detected or completed within the timeout limit. |
| **`-32006`** | `AUTH_UNAUTHORIZED` | Invalid or missing security token during handshake. |
| **`-32007`** | `NAVIGATION_FAILED` | Target URL failed to resolve, DNS error, or connection reset. |
| **`-32008`** | `MACRO_STEP_FAILED` | A macro step could not resolve or perform its target; data carries a fresh snapshot. |
| **`-32009`** | `DISPATCHED_UNCONFIRMED` | The request reached the extension but no acknowledgement arrived before the deadline. The side effect may have occurred; data carries `{ method, timeoutMs }`. |
| **`-32010`** | `SNAPSHOT_STALE` | The page navigated or reloaded since the snapshot that produced the referenced ID; take a new snapshot. |
| **`-32011`** | `FEATURE_DISABLED` | The method is disabled on this daemon (currently `page.eval` with `--no-eval`). |

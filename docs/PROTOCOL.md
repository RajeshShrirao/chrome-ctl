# Wire Protocol Specification: `chrome-ctl`

**Document Version:** 1.0  
**Transport:** WebSocket (`ws://127.0.0.1:9229/ws`)  
**Encoding:** UTF-8 JSON  
**Framing Model:** JSON-RPC 2.0 Bi-directional Envelopes  

---

## 1. Connection Handshake & Authentication

### 1.1 Handshake Flow
1. Extension connects to `ws://127.0.0.1:9229/ws?token=<64_CHAR_HEX_TOKEN>`.
2. Daemon verifies the token against `~/.chrome-ctl/auth_token`.
3. If token matches, connection is accepted, and daemon broadcasts:
   ```json
   {
     "jsonrpc": "2.0",
     "method": "system.ready",
     "params": {
       "version": "1.0.0",
       "daemonUptimeSec": 42,
       "attachedTabs": []
     }
   }
   ```
4. If token is invalid or missing, daemon responds with HTTP `401 Unauthorized` and terminates the TCP socket immediately.

### 1.2 Heartbeat (Liveness Keep-Alive)
* The Extension's Offscreen Document sends a ping every **15 seconds**:
  ```json
  { "jsonrpc": "2.0", "method": "system.ping", "params": { "timestamp": 1729725600 } }
  ```
* Daemon replies immediately with:
  ```json
  { "jsonrpc": "2.0", "result": { "status": "pong", "timestamp": 1729725600 }, "id": null }
  ```

## 2. Standard Message Framing

### 2.1 Request Envelope (CLI $\rightarrow$ Daemon $\rightarrow$ Extension)
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "method": "<domain>.<action>",
  "params": {
    "tabId": 142058291,
    "..." : "..."
  }
}
```

* `id` *(string, required)*: Monotonically increasing or UUID string generated by the caller.
* `method` *(string, required)*: Method in `<domain>.<action>` syntax.
* `params` *(object, optional)*: Command-specific arguments. If `tabId` is omitted, the Extension defaults to the currently active tab.

### 2.2 Success Response Envelope (Extension $\rightarrow$ Daemon $\rightarrow$ CLI)
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "result": {
    "status": "ok",
    "data": {}
  }
}
```

### 2.3 Error Response Envelope
```json
{
  "jsonrpc": "2.0",
  "id": "req_01h7v83k92",
  "error": {
    "code": -32001,
    "message": "Element not found or not interactable",
    "data": {
      "elementId": 5,
      "details": "Element [5] was scrolled out of viewport or mutated before click."
    }
  }
}
```

### 2.4 Event Envelope (Unsolicited Extension $\rightarrow$ Daemon)
```json
{
  "jsonrpc": "2.0",
  "method": "event.<eventName>",
  "params": {
    "tabId": 142058291,
    "data": {}
  }
}
```

## 3. Core RPC Methods

### 3.1 Session & Tab Management

#### `session.status`
Checks connection health, active Chrome tabs, and debugger attachment status.
* **Params:** `{}`
* **Result:**
  ```json
  {
    "status": "ok",
    "extensionConnected": true,
    "activeTab": {
      "tabId": 142058291,
      "title": "LinkedIn - Feed",
      "url": "https://www.linkedin.com/feed/"
    },
    "debuggerAttached": true
  }
  ```

#### `tab.list`
Returns all open tabs in the current Chrome window.
* **Params:** `{ "windowId"?: number }`
* **Result:**
  ```json
  {
    "tabs": [
      { "tabId": 101, "title": "Google", "url": "https://www.google.com", "active": false },
      { "tabId": 102, "title": "LinkedIn", "url": "https://www.linkedin.com/feed/", "active": true }
    ]
  }
  ```

#### `tab.open`
Navigates the active tab or opens a new tab.
* **Params:**
  ```json
  {
    "url": "https://clutch.co/directory",
    "newTab": false
  }
  ```
* **Result:**
  ```json
  {
    "tabId": 102,
    "url": "https://clutch.co/directory",
    "title": "Top Web Developers - Clutch",
    "loaded": true
  }
  ```

#### `tab.switch`
Switches focus and automation control to specified `tabId`.
* **Params:** `{ "tabId": 101 }`
* **Result:** `{ "success": true, "activeTabId": 101 }`

### 3.3 Humanized Actions (Dispatched via `chrome.debugger`)

#### `action.click`
Executes Bézier trajectory mouse movement and dispatches trusted mouse click events.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id": 2,
    "doubleClick"?: false,
    "snap"?: true
  }
  ```
* **Result:**
  ```json
  {
    "success": true,
    "action": "click",
    "target": { "id": 2, "tag": "button", "label": "Start a post" },
    "coordinates": { "x": 542, "y": 138 },
    "durationMs": 340,
    "snapshot"?: { /* Included if snap == true */ }
  }
  ```

#### `action.type`
Focuses target element and dispatches cadence keystrokes with variable delays and optional typos.
* **Params:**
  ```json
  {
    "tabId"?: 102,
    "id": 4,
    "text": "Hello world! We are launching today.",
    "enter"?: true,
    "typoRate"?: 0.02,
    "snap"?: false
  }
  ```
* **Result:**
  ```json
  {
    "success": true,
    "charsTyped": 36,
    "durationMs": 2450,
    "typosInjected": 1,
    "stateDelta": "[6] <button:submit> \"Send\" is now (enabled)"
  }
  ```

#### `action.press`
Dispatches a trusted individual key press (`Enter`, `Tab`, `Escape`, `ArrowDown`, etc.).
* **Params:**
  ```json
  {
    "key": "Enter",
    "modifiers"?: ["Control"]
  }
  ```
* **Result:** `{ "success": true, "key": "Enter" }`

#### `action.scroll`
Executes momentum wheel scrolling with micro-pauses.
* **Params:**
  ```json
  {
    "direction": "down",
    "amount": 0.8
  }
  ```
* **Result:**
  ```json
  {
    "scrolledPixels": 720,
    "newScrollY": 720,
    "viewportPercent": 38
  }
  ```

#### `action.upload`
Attaches a local file to a file input node (`<input type="file">`).
* **Params:**
  ```json
  {
    "id": 5,
    "filePath": "/Users/user/Desktop/logo.png"
  }
  ```
* **Result:**
  ```json
  {
    "success": true,
    "fileName": "logo.png",
    "fileSize": 45120
  }
  ```

### 3.6 Resilient Targets & Macro Replay

`page.describe` and `page.resolve` expose the multi-tier selector engine used by macros.

#### `page.describe`
* **Params:** `{ "tabId"?: 4, "id": 12 }`
* **Result:** `{ "target": { "testId"?: "...", "ariaLabel"?: "...", "role"?: "button", "text"?: "...", "tag"?: "button", "type"?: "...", "xpath"?: "...", "cssSelector"?: "..." } }`
* Resolves `id` against the latest snapshot index; returns `-32001` when the element is gone.

#### `page.resolve`
* **Params:** `{ "tabId"?: 4, "target": { ... }, "timeoutMs"?: 3000 }`
* **Result:** `{ "id": 12, "tag": "button", "type": "", "label": "Continue", "x": 410, "y": 650, "w": 120, "h": 36, "matchedTier": "ariaLabel" }`
* Tiers are attempted in order: `testId`, `ariaLabel` (+`role`), `text`, `xpath`, `cssSelector`. Polls every 150 ms until `timeoutMs` (default 3000, max 15000). The returned `id` can be passed to `action.click`, `action.type`, or `action.upload`.

Macro methods are handled by the daemon itself and replayed locally.

| Method | Params | Result |
| :--- | :--- | :--- |
| `macro.start` | `{ "name": "lead_search" }` | `{ "name", "started": true, "steps": 0 }` |
| `macro.save` | `{ "params"?: ["search_term"], "description"?: "..." }` | `{ "path", "name", "steps", "parameters" }` |
| `macro.list` | `{}` | `{ "macros": [{ "name", "description", "parameters", "steps", "modifiedAt" }] }` |
| `macro.run` | `{ "name": "lead_search", "vars": { "search_term": "Design Studios" } }` | `{ "macro", "stepsRun", "durationMs", "completed": true }` |

When replay cannot resolve or perform a step, `macro.run` fails with code `-32008` and data `{ "status": "macro_step_failed", "macro", "failed_step_id", "reason", "current_snapshot", "remaining_steps" }`.

## 4. Error Code Reference

| Code | Name | Description |
| :--- | :--- | :--- |
| **`-32000`** | `CONNECTION_ERROR` | WebSocket or daemon bridge connection failed. |
| **`-32001`** | `ELEMENT_NOT_FOUND` | Specified element ID was not found in the current tab's active index map. |
| **`-32002`** | `ELEMENT_NOT_INTERACTABLE`| Target element is obscured, detached from DOM, or has `pointer-events: none`. |
| **`-32003`** | `TAB_NOT_FOUND` | The requested `tabId` does not exist or was closed. |
| **`-32004`** | `DEBUGGER_DETACHED` | `chrome.debugger` was forcibly detached or blocked. |
| **`-32005`** | `SSO_TIMEOUT` | No Google OAuth popup was detected or completed within the timeout limit. |
| **`-32006`** | `AUTH_UNAUTHORIZED` | Invalid or missing security token during handshake. |
| **`-32007`** | `NAVIGATION_FAILED` | Target URL failed to resolve, DNS error, or connection reset. |
| **`-32008`** | `MACRO_STEP_FAILED` | A macro step could not resolve or perform its target; data carries a fresh snapshot. |
